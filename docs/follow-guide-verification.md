# 기웃 — 폴더, 코스, 방향 안내

검증일: 2026-09-14. 기존 지도·사진·댓글·좋아요·AR 기록을 유지하고 추가한 범위입니다.

## 사용 흐름

- 장소의 저장 버튼 → 여러 스크랩 폴더 선택 또는 새 폴더 생성.
- 저장 → 스크랩 폴더 → 순서 편집 → 코스 만들기. 산책·러닝, 서로 다른 장소 2~6곳.
- 코스는 폴더와 별도로 저장됩니다. 폴더를 지워도 장소는 기본 폴더에 보관되며 공유한 코스가 바뀌지 않습니다.
- 장소 사진 상세 또는 공유 코스 → 같이 기웃거리기 → 현재 위치에서 경로 찾기 → 실제 도보 경로·거리·예상 시간 확인 → 발자국/지도 안내 시작.
- 도착 시 해당 기록을 서버에서 다시 조회합니다. 원본 기록을 열어 작성자·등록 시각·사진·이야기·댓글·반응을 보고, 다음 경유지로 이동할 수 있습니다.

## 외부 연결

공식 문서: https://developers.kakao.com/docs/ko/kakaomap/rest-api

서버 환경변수 `KAKAO_REST_API_KEY`가 필요합니다. 기존 `KAKAO_JAVASCRIPT_KEY`는 지도 표시용이며 대체할 수 없습니다. 키는 클라이언트 코드에 넣지 않습니다.

`POST /api/walking-route`는 공개 스팟·공유 코스에서도 사용할 수 있으며, 서버에서 `GET https://dapi.kakao.com/v2/routing/walk`를 요청합니다. `start_x/y`, `end_x/y`, 순서가 있는 `via_x/y`(최대 5곳), WGS84를 사용합니다. 응답의 legs/steps/path.points를 검증하여 지도와 방향 계산에 사용합니다. 임의의 직선 연결은 길안내 경로로 제공하지 않습니다.

이번 검증 시 서버에 등록된 것은 지도용 키뿐입니다. 경로용 REST 키 미등록 시 `ROUTING_NOT_CONFIGURED`를 반환하고 재시도·카카오맵 길찾기를 제공합니다. 실제 카카오 경로 요청 성공과 현장 안내는 연결 후 검증해야 합니다.

## 동작의 한계

흰 고양이 발자국(최대 불투명도 0.62)은 GPS와 방위각을 이용한 카메라 방향 표시입니다. 바닥 인식, 공간 앵커, 지면 고정, WebXR 정밀 AR은 구현 범위에 포함되지 않습니다.

위치 오차가 40m를 초과하거나 오래된 위치이면 발자국을 숨깁니다. 방향이 없거나 불안정하면 지도 안내로 전환합니다. 목적지 20m 이내·위치 정확도 20m 이내인 연속 위치값 3개 이상이 최소 4초간 유지되어야 도착합니다. GPS 급변과 동일 시각의 반복 값으로 완주되지 않습니다. 경로 이탈 역시 연속 값과 오차를 고려합니다.

안내 일시정지·종료·화면 이탈 시 카메라, GPS 구독, 방향 리스너를 해제합니다. 종료 후 뒤늦게 허용된 카메라 스트림도 즉시 정지합니다. 감소된 동작 설정에서는 발자국 반복 모션을 줄입니다.

## 완료한 검증

`node --test tests/follow-and-collections.test.mjs` — 17개 통과. 모두 합성 좌표·센서·카카오 응답과 메모리 SQLite를 사용한 자동 테스트이며 실외 보행 테스트가 아닙니다.

| 항목 | 검증 방식 |
| --- | --- |
| 기존 스크랩 이전, 여러 폴더에 담기, 마지막 폴더에서 빼기 | 실제 API 핸들러 + 격리 SQLite |
| 폴더 순서 저장, 코스 순서 독립성, 폴더 삭제 후 기록 보존 | 실제 API 핸들러 + 격리 SQLite |
| 타인 폴더·코스 수정 차단, 중복·오래된 순서 거부 | 실제 API 핸들러 + 테스트 사용자 |
| 키 없음, 경로 없음, 권한 오류, 시간 초과, 경유지 순서 | 실제 서버 핸들러 + 합성 상위 API 응답 |
| 경로 다음 구간 방향, 북쪽 0° 경계, GPS 급변·오차 | 순수 계산 테스트 |
| 단일 위치값으로 도착 금지, 안정적인 도착·경로 이탈 | 시간순 합성 GPS 값 |
| 카메라·위치 권한 거부, 방향 미지원, 센서 정상 허용 | 주입한 테스트 센서 |
| 종료·지도 전환·종료 후 늦은 카메라 허용 | 스트림·리스너 해제 검증 |

데스크톱 Cloud Chrome 브라우저에서 기존 기록·댓글 조회, 상세의 새 버튼, 경로 미리보기 진입과 종료, 위치 권한 거부 오류·재시도·외부 길찾기 표시, 저장/스크랩 폴더/공유 코스 탭을 확인했습니다. 미리보기의 비로그인 상태 때문에 로그인 후 폴더 생성 UI는 브라우저에서 직접 실행하지 않았으며 API 테스트로 검증했습니다.

타입 검사와 배포용 빌드를 통과했습니다. 브라우저에서 발견한 길안내 창의 중복 좌표 이동을 수정했습니다.

## 남은 실제 기기 검증

- iPhone Safari 및 Android Chrome 실물 기기: 아직 테스트하지 않았습니다.
- REST 키를 등록하고 현재 앱에서 도보 API 사용 권한이 있는지 확인한 뒤 실제 경로·거리·도보 시간을 점검해야 합니다.
- HTTPS 배포 주소에서 후면 카메라·GPS·방향 권한 허용/거부, 좌우 회전 반응, 교차로 경로 이탈, 정지와 재개, 목적지 도착 및 다음 AR 기록을 확인해야 합니다.
- 폰 잠금/다른 앱 이동 후 카메라가 꺼지고 수동 재개하는지, 카카오맵 경로와 실제 통행 가능한 길이 맞는지 확인해야 합니다.

테스트 센서·인증 대체는 테스트 파일 내부에만 존재하며 사용자 화면이나 배포 코드에 시뮬레이션 모드를 추가하지 않았습니다.
